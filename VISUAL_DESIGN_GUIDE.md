## 📏 Component Dimensions

### Navigation Bar
- Height: `py-4` (16px padding)
- Fixed position at top
- Gap between items: `gap-8` (32px)

### Sections
- Vertical padding: `py-20` (80px)
- Horizontal padding: `px-4 sm:px-6 lg:px-8`
- Max width: `max-w-4xl` or `max-w-6xl`

### Cards
- Padding: `p-6` or `p-8` (24px or 32px)
- Border radius: `rounded-2xl` (16px)
- Border width: `border` (1px)

### Buttons
- Padding: `px-8 py-4` (32px x 16px)
- Border radius: `rounded-xl` (12px)
- Font: `font-semibold` with `uppercase` or normal

## ✨ Animation Types

### Scroll Reveal
- Direction: up, down, left, right
- Distance: 30px
- Duration: 0.8s
- Trigger: onViewport

### Hover Effects
- Scale: `hover:scale-105` (5% increase)
- Translate Y: `hover:y-[-8px]` or `hover:y-[4px]`
- Translate X: `hover:x-[4px]`
- Shadow increase: `hover:shadow-xl`
- Color change: `transition-colors`

### Stagger Animation
- Container: StaggerContainer
- Delay per item: 0.15s
- Creates cascade effect

## 🎯 Responsive Behavior

### Mobile (< 640px)
```
┌─────────────────────────────┐
│ [Logo] [Menu]               │
├─────────────────────────────┤
│        (Stacked)            │
│  Full-width components      │
│  Single column layouts      │
│  Larger text sizes          │
│  Touch-friendly buttons     │
└─────────────────────────────┘
```

### Tablet (640px - 1024px)
```
┌─────────────────────────────────────┐
│ [Logo] [Nav Links] [Button]         │
├─────────────────────────────────────┤
│  2-column grid layouts              │
│  Balanced spacing                   │
│  Medium text sizes                  │
└─────────────────────────────────────┘
```

### Desktop (> 1024px)
```
┌───────────────────────────────────────────────────────┐
│ [Logo]  [Nav] [Nav] [Nav]                   [Button]  │
├───────────────────────────────────────────────────────┤
│  3+ column grid layouts                               │

```
