## 🎬 Animation & Effects

### Scroll Reveal Animations ✨
Every major element fades in + slides when scrolling:
- **Fade**: Opacity 0 → 1
- **Slide**: Moves based on direction (up/down/left/right)
- **Duration**: 0.8 seconds
- **Easing**: Professional cubic-bezier curve
- **Trigger**: Viewport entry with margin detection
- **Once**: Fires only once per page load

### Hover Interactions 🎯
- **Scale**: 1.05x (5% size increase)
- **Lift**: -8px Y-axis movement
- **Glow**: Color-tinted shadows
- **Transition**: Smooth 300-400ms

### Continuous Animations 🔄
- **Background Glows**: 8-second loop, infinite
- **Icon Rotation**: 20-second continuous spin
- **Scroll Indicator**: Y-axis bobbing animation

### Staggered Animations 📊

- **Smooth cascade effect**
